# Challenge5
Problem Statement:
Create a menu-driven C program that lets a user choose a mathematical operation. After each operation, display the menu again. The program
must stop only when the user selects Exit.

Algorithm:
1.	Start
2.	Display the menu.
3.	Read the user's choice.
4.	Use a switch statement to perform the selected operation.
5.	If a is not equal to 0, calculate \(x=-b/a\) and display the result.
6.	Otherwise, display “No solution.”
7.	Multiply fact by each integer from 1 to n using a for loop.
8.	If d is greater than 0, calculate its square root using a loop, find both roots, and display them.
9.	If d is equal to 0, calculate and display the equal roots.
10.	If the choice is not 4, display the menu again. If the choice is 4, stop the program.
11.	Stop
